# Procedural Structures Mod

A Minecraft Fabric mod that generates procedural structures with themed customization and **full keybinding support**!

## Features

### Structure Generation
- **Spiral Towers**: Elegant curved structures with platforms
- **Dome Structures**: Smooth spherical buildings with entrances
- **Floating Islands**: Suspended landmasses with vegetation

### 15 Themed Palettes
1. **Default** - Classic Minecraft blocks
2. **Nether** - Fire-resistant nether materials  
3. **End** - Mysterious end stone and chorus
4. **Medieval** - Stone bricks and cobblestone
5. **Modern** - Clean concrete and glass
6. **Nature** - Wood and organic materials
7. **Ocean** - Aquatic prismarine blocks
8. **Desert** - Sandstone and terracotta
9. **Snow** - Ice and snow blocks
10. **Jungle** - Tropical jungle woods
11. **Red** - Red-themed blocks
12. **Blue** - Blue-themed blocks  
13. **Green** - Green-themed blocks
14. **Purple** - Purple-themed blocks
15. **Rainbow** - Colorful mixed palette

### Configuration System
- Size control (1-10 scale)
- Theme cycling
- Structure type preferences

## Usage

### Keybindings ✨ NEW!
**Configure in:** Options → Controls → Key Binds → Procedural Structures

- **Generate Structure:** `G` key (default, customizable)
- **Cycle Theme:** `T` key (default, customizable)  
- **Show Configuration:** `H` key (default, customizable)

### Commands (Still Available)
- `/generatestructure` - Generate a random themed structure at your location
- `/structuretheme` - Cycle to the next theme (shows preview)
- `/structureconfig` - Display current configuration settings

### Examples
1. Press `T` (or your custom key) to select themes
2. Press `G` (or your custom key) to generate structures instantly
3. Press `H` (or your custom key) to see current settings
4. Customize keybindings in Controls menu for your preferences!

## Installation
1. Install Fabric Loader 0.16.14+ for Minecraft 1.21.7 - 1.21.8
2. Install Fabric API 0.129.0+1.21.7+ or 0.129.0+1.21.8+
3. Place the mod JAR in your mods folder
4. Launch Minecraft and enjoy!
