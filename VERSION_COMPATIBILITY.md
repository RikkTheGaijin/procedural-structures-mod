# Version Compatibility Guide

## Supported Minecraft Versions

This mod supports **Minecraft 1.21.7** and **Minecraft 1.21.8**.

## Required Dependencies

### For Minecraft 1.21.7:
- **Fabric Loader**: 0.16.14 or higher
- **Fabric API**: 0.129.0+1.21.7 or compatible version
- **Java**: 21 or higher

### For Minecraft 1.21.8:
- **Fabric Loader**: 0.16.14 or higher  
- **Fabric API**: 0.129.0+1.21.8 or compatible version
- **Java**: 21 or higher

## Installation Notes

1. **Automatic Detection**: The mod will automatically work with both 1.21.7 and 1.21.8 - no special configuration needed
2. **Fabric API Compatibility**: Make sure to download the Fabric API version that matches your Minecraft version
3. **Single JAR**: One mod file works for both supported Minecraft versions

## Version Range Explanation

The mod uses the version range `>=1.21.7 <1.22.0` which means:
- ✅ **Minecraft 1.21.7** - Supported
- ✅ **Minecraft 1.21.8** - Supported  
- ❌ **Minecraft 1.21.6** and earlier - Not supported
- ❌ **Minecraft 1.22.0** and later - Not supported (when released)

## Backwards Compatibility

While this mod supports 1.21.7, it was originally developed for 1.21.8. All features should work identically on both versions since there were no major API changes between these versions that affect this mod's functionality.
