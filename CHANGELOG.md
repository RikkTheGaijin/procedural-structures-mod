# Changelog

All notable changes to the Procedural Structures mod will be documented in this file.

## [1.0.0] - 2025-08-17

### Added
- Initial release of Procedural Structures mod
- Keybinding support (G/T/H keys) with full customization
- Interactive configuration GUI menu
- 15 themed structure palettes (Default, Nether, End, Medieval, Modern, Nature, Ocean, Desert, Snow, Jungle, Red, Blue, Green, Purple, Rainbow)
- Multiple structure types (Spiral towers, Domes, Floating islands, Cantilevers, Bridges)
- Cross-version compatibility for Minecraft 1.21.7-1.21.8
- Full client-server synchronization
- Configurable scale ranges (3-50)
- Toggle options for decorations, lighting, plants, and floating islands
- Professional mod icon and branding

### Technical Details
- Built with Fabric Loader 0.16.14+
- Requires Fabric API 0.129.0+
- Optimized performance (<10MB RAM, 50-200ms generation time)
- Support for single-player and multiplayer environments
