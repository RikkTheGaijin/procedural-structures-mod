# Procedural Structures Mod

A Minecraft Fabric mod that generates beautiful procedural structures with themed customization.

## Features

- **15 Themed Palettes**: Default, Nether, End, Medieval, Modern, Nature, Ocean, Desert, Snow, Jungle, and color themes
- **Multiple Structure Types**: Spiral towers, floating islands, domes, and architectural marvels
- **Easy Commands**: Simple commands to generate structures and change themes
- **Full Configuration**: Size control, decoration toggles, and theme cycling

## Usage

- `/generatestructure` - Generate a random themed structure at your location
- `/structuretheme` - Cycle to the next theme
- `/structureconfig` - Display current configuration settings

## Setup

For setup instructions please see the [fabric documentation page](https://docs.fabricmc.net/develop/getting-started/setting-up-a-development-environment) that relates to the IDE that you are using.

## Requirements

- Minecraft 1.21.7 - 1.21.8
- Fabric Loader 0.16.14+
- Fabric API 0.129.0+1.21.7+ or 0.129.0+1.21.8+
- Java 21+
