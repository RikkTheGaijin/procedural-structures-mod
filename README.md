## ✨ Features

### 🏗️ **Instant Structure Generation**
- **G** key - Generate structures instantly at your location
- **T** key - Cycle through 15 unique themes
- **H** key - Open configuration menu

### 🎨 **15 Themed Palettes**
- **Default** - Classic Minecraft blocks
- **Nether** - Fire-resistant nether materials  
- **End** - Mysterious end stone and chorus
- **Medieval** - Stone bricks and cobblestone
- **Modern** - Clean concrete and glass
- **Nature** - Wood and organic materials
- **Ocean** - Aquatic prismarine blocks
- **Desert** - Sandstone and terracotta
- **Snow** - Ice and snow blocks
- **Jungle** - Tropical jungle woods
- **Red/Blue/Green/Purple** - Color-themed blocks
- **Rainbow** - Colorful mixed palette

### 🖥️ **Interactive Configuration UI**
- **Theme Selection** - Click to cycle through all options
- **Scale Adjustment** - Slider controls for structure size (3-50)
- **Feature Toggles**:
  - Decorations (Glass canopies, waterfall effects)
  - Lighting (Lanterns and light sources)
  - Plants (Vegetation and organic elements)
  - Floating Islands (Sky-based generation)

### 🏛️ **Structure Types**
- **Spiral Towers** - Elegant curved structures with platforms
- **Dome Structures** - Smooth spherical buildings
- **Floating Islands** - Suspended landmasses with vegetation
- **Cantilevers** - Dramatic overhanging platforms
- **Bridges** - Connecting structures across terrain

## 🎮 Usage

### Quick Start
1. Join any world (Creative or Survival)
2. Press **G** to generate your first structure
3. Press **T** to cycle through themes
4. Press **H** to open the configuration menu
5. Customize settings and generate amazing structures!

### Commands (Alternative)
- `/generatestructure` - Generate a structure
- `/structuretheme` - Change theme
- `/structureconfig` - Open configuration info

### Keybinding Customization
1. Go to **Options** → **Controls** → **Key Binds**
2. Find **"Procedural Structures"** category
3. Customize G/T/H keys to your preference

## 🔧 Installation

### Requirements
- **Minecraft** 1.21.7 or 1.21.8
- **Fabric Loader** 0.16.14+
- **Fabric API** 0.129.0+

### Steps
1. Install [Fabric Loader](https://fabricmc.net/use/)
2. Download [Fabric API](https://modrinth.com/mod/fabric-api)
3. Download Procedural Structures Mod
4. Place both JARs in your `mods` folder
5. Launch Minecraft with Fabric profile
