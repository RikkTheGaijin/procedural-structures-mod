# Procedural Structures Mod

A Minecraft Fabric mod that generates beautiful procedural structures inspired by GPT-5's architectural creativity. Create stunning spiral towers, floating islands, cantilevered platforms, and architectural marvels with customizable themes and styles!

## ✨ Features

Based on the original GPT-5 procedural building script, this mod recreates the same magical structures including:

- **Spiral Towers**: Multi-turn towers with organic spiraling architecture
- **Floating Islands**: Suspended gardens with hanging chains and lanterns
- **Dome Structures**: Shrinking circular layer domes with central pillars
- **Cantilevered Platforms**: Extended platforms with decorative elements
- **Glass Canopies**: Transparent overhangs using stained glass
- **Architectural Bridges**: Connecting walkways between structures
- **Decorative Elements**: End rods, lanterns, plants, and signature blocks

## 🎨 Themes & Customization

The mod now includes **15 different themes** for creating unique architectural styles:

### **Dimension Themes**
- **Default**: Mixed blocks from all categories (original style)
- **Nether**: Netherrack, basalt, blackstone, crimson/warped wood
- **End**: End stone, purpur blocks, obsidian, purple/magenta palette
- **Overworld**: Natural stone, wood, dirt, leaves - organic builds

### **Color Themes**
- **Red**: Red terracotta, nether bricks, redstone blocks, crimson wood
- **Blue**: Blue concrete, prismarine, lapis blocks, ice blocks
- **Green**: Emerald blocks, moss, jungle wood, lime concrete
- **Yellow**: Gold blocks, glowstone, honey blocks, sandstone
- **Purple**: Purpur blocks, amethyst, magenta concrete
- **Orange**: Copper blocks, pumpkins, acacia wood, orange concrete
- **Black**: Blackstone, coal blocks, dark oak, obsidian
- **White**: Quartz, calcite, birch wood, snow blocks

### **Material Themes**
- **Wooden**: All wood types and variants - rustic builds
- **Stone**: All stone variants - fortress-like structures
- **Glass**: Transparent blocks - crystalline architecture

## 🎮 Usage

### Commands
- `/generatestructure` - Generate a structure with current theme
- `/structureconfig` - Show current configuration settings
- `/structuretheme` - Cycle to the next theme

### Configuration Options
- **Scale Range**: Structures size from 8-28 blocks (configurable)
- **Decorations**: Enable/disable glass canopies and waterfalls
- **Lighting**: Enable/disable lanterns and light sources
- **Plants**: Enable/disable vegetation and organic elements
- **Floating Islands**: Enable/disable floating island generation

## 🔧 Installation

1. Make sure you have Minecraft 1.21.7 - 1.21.8 and Fabric Loader installed
2. Download Fabric API
3. Place this mod's JAR file in your mods folder
4. Launch Minecraft with the Fabric profile

## 🏗️ Building from Source

```bash
./gradlew build
```

The built JAR will be in `build/libs/`
